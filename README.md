# AI Challenge 2026

Учебные задачи по GigaChat API. Одна папка — одна задача: `w<неделя>t<задача>`
(`w1t1`, `w1t2`, `w2t1`, ...). Задачи независимы и запускаются каждая сама по себе.

## Задачи

| Папка | Что делает |
|-------|------------|
| [w1t1](w1t1) | Авторизация в GigaChat API, список моделей и остаток токенов |
| [w1t2](w1t2) | Запрос к GigaChat или шлюзу Veai: выбор провайдера и модели, ответ на промпт |
| [w1t3](w1t3) | Сравнение моделей: 2 уровня рассуждений × 4 способа решения на общем наборе задач |

## Наборы данных

| Файл | Что внутри |
|------|------------|
| [tasks.json](tasks.json) | 12 задач с эталонными ответами для сравнения моделей (используется в `w1t3`) |
| [tasks_short.json](tasks_short.json) | Сокращённый набор из 7 задач для быстрой проверки |

## Подготовка

1. Python 3.10+ (внешние зависимости не нужны).
2. Ключ авторизации GigaChat API — в личном кабинете Сбера
   (Base64 от Client ID и Client Secret).
3. Создайте `.env` **вне репозитория** — например `D:\projects\ai\.env` с содержимым:

```
GIGACHAT_CREDENTIALS=<ваш ключ авторизации>
VEAI_CREDENTIALS=<персональный API-ключ https://app.veai.ru>
```

`VEAI_CREDENTIALS` нужен только задачам, которые обращаются к шлюзу Veai (`w1t2`, `w1t3`).

Файл `.env` добавлен в `.gitignore` как страховка, но ключ лучше держать за пределами
папки репозитория: репозиторий публичный, а попавший в историю git секрет
очистить нельзя — ключ придётся перевыпускать.

Сертификаты НУЦ Минцифры нужны для TLS: Python не доверяет корневому сертификату
GigaChat по умолчанию. Они публичные и лежат в `w1t1/certs/` и `w1t2/certs/`.

## Запуск задачи

```powershell
python .\w1t1\main.py
```

Полезные флаги `w1t1`:

```powershell
python .\w1t1\main.py --env D:\projects\ai\.env   # указать файл ключа явно
python .\w1t1\main.py --no-cache                  # переавторизоваться, минуя кэш токена
```

Файл `.env` ищется от папки задачи вверх по дереву каталогов. Кэш токена
хранится в `w1t1/.cache/` и переиспользуется, пока токен не истёк (30 минут).

Код возврата: `0` — успех, `1` — ошибка (нет ключа, отказ авторизации, нет сети).
