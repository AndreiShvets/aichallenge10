# w3t3 — состояние задачи как конечный автомат

Продолжение [w3t2](../w3t2/README.md): профили и три слоя памяти дополнены состоянием задачи. Для каждой задачи хранятся этап, текущий шаг, ожидаемое действие, резюме и признак паузы. Состояние сохраняется вместе с рабочей памятью и передаётся агенту в контексте.

## Запуск

```powershell
python .\w3t3\main.py
python .\w3t3\main.py --provider veai --model openai/gpt-4o-mini
```

Ключи, профили и ввод команд описаны в [w3t2](../w3t2/README.md). По умолчанию Tab дополняет команды при наличии `readline`; `--command-prefix` включает сокращения после Enter. Автоматического определения смены задачи нет: используйте `/task ИМЯ` для новой задачи и `/task open НОМЕР` для возврата к архивной. Команда `/clear` также явно закрывает текущую задачу. Параметр `--rules-only` из предыдущих версий больше не используется.

## Этапы и команды

Допустимый порядок: `planning → execution → validation → done`. Проверка перехода выполняется программой до сохранения; этап меняет только явная команда пользователя. Слова ассистента или просьба в диалоге не меняют состояние.

| Команда | Действие |
|---|---|
| `/state` | показать состояние |
| `/state step ТЕКСТ` | записать текущий шаг |
| `/state expected ТЕКСТ` | записать ожидаемое действие |
| `/state summary ТЕКСТ` | сохранить резюме задачи для продолжения |
| `/state go execution confirm` | утвердить план и перейти к выполнению |
| `/state go validation` | перейти к проверке после выполнения |
| `/state go done confirm` | подтвердить проверку и завершить задачу |
| `/state pause` | поставить задачу на паузу |
| `/state resume` | продолжить задачу |

Пример: опишите задачу и попросите составить план, затем сохраните важный контекст командой `/state summary ...`. После утверждения выполните `/state go execution confirm`, а по завершении работы — `/state go validation`. После проверки команда `/state go done confirm` завершит жизненный цикл. Попытка `/state go done confirm` на этапе планирования будет отклонена.

Пауза доступна на любом этапе. Пока задача на паузе, обычные запросы не выполняются; `/state resume` возобновляет работу с сохранённым состоянием. Состояние относится к задаче и профилю, сохраняется на диске и восстанавливается после перезапуска и переключения задач. Для продолжения без повторных объяснений сохраняйте важные сведения в резюме и памяти.

**Граница гарантии:** код запрещает недопустимые изменения состояния. Модель получает указание придерживаться этапа, но программа не умеет надёжно распознавать и блокировать любой текст реализации или финала в ответе. Существующие инструменты агента не выполняют реализацию проекта; нельзя считать текстовый ответ доказательством выполнения или валидации.
