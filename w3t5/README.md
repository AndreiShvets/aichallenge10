# w3t5 — обновление памяти

Продолжение [w3t4](../w3t4/README.md): агент сохраняет актуальные значения фактов, время записи и историю изменений. Профили, инварианты и жизненный цикл задачи остаются доступными.

## Запуск

```powershell
python .\w3t5\main.py
python .\w3t5\main.py --provider veai --model openai/gpt-4o-mini
```

## Запись и просмотр

`/memory` показывает слои памяти, `/memory-log` — замены фактов. Команда `/remember ключ=значение [long|work]` позволяет записать факт явно. Для ключей `срок`, `статус`, `версия`, `требование`, `подход` хранится одно актуальное значение в рабочей памяти задачи; для срока принимается также ключ `дедлайн`. При изменении подхода запись сохраняется в историю решений в долговременной памяти. Время каждой записи и журнал замен сохраняются на диске. Более ранняя запись не заменяет более позднюю; при одинаковом времени побеждает последняя обработанная запись.

Явные изменения из сообщения обрабатываются до ответа. При включённом извлечении модель дополнительно разбирает формулировки пользователя; `--no-extract` оставляет ограниченные правила. Например:

```text
Срок: 1 мая 2026
Срок перенесли с 1 мая 2026 на 15 мая 2026
Статус: согласование
Статус теперь выполнение
Требование отменили
Подход: локальная обработка
Подход теперь обработка на сервере
/memory
/memory-log
```

На `/state go done confirm` рабочие факты и контекст завершённой задачи очищаются; долговременные факты и история решений остаются. Переход возможен только после `execution` и `validation` (см. [w3t3](../w3t3/README.md)).

## Границы актуальности

В основном пользовательском запросе буквальные старые значения известных изменяемых фактов маскируются в истории, сводке и сохранённом контексте задачи. Это не семантическая гарантия: перефразировки, короткие значения и совпадения с другими актуальными фактами могут оставаться. Служебные запросы и другие блоки контекста также не гарантируют отсутствие старых значений. История изменений хранится для аудита и не является списком действующих решений.

Локальный сценарий с четырьмя изменениями, вопросами после них и очисткой памяти запускается без платных запросов:

```powershell
python -m unittest discover -s w3t5 -p test_memory.py -v
```

Заглушка формирует ответы из актуального блока памяти: она проверяет передачу данных и фильтрацию, но не поведение реальной модели. Для проверки модели можно менять значения по очереди, после каждого изменения задавая вопрос об актуальном значении и вручную подсчитывая устаревшие ответы. Это требует платных запросов.
