# AGENTS.md — правила репозитория aichallenge10

Учебные проекты по GigaChat API и шлюзу Veai. Одна папка — одна задача.
Этот файл читается автоматически в каждой сессии: он описывает то, что нельзя
вывести из чтения кода.

## Структура

| Папка | Что делает | README |
|---|---|---|
| `w1t1` | Авторизация, список моделей, остаток токенов | — |
| `w1t2` | Один запрос к GigaChat или Veai: выбор провайдера, модели, параметров | `w1t2/README.md` |
| `w1t3` | Сравнение моделей: 2 уровня рассуждений × 4 способа решения | `w1t3/README.md` |
| `w1t4` | Влияние температуры: 3 температуры × 5 повторов, метрики различия | `w1t4/README.md` |
| `w1t5` | Три класса моделей: маленькая, средняя, флагманская — верность и цена | `w1t5/README.md` |

Общие файлы в корне: `tasks.json` (12 задач с эталонами), `tasks_short.json`
(7), `ai_models_prices.json` (цены моделей, классы, курс валюты).

## Новая задача

1. Папка `w<неделя>t<задача>` (`w2t1` и т. д.) — отдельная, самодостаточная.
2. Скопировать `gigachat_client.py`, `veai_client.py` и `certs/` из последней
   задачи. **Копия, а не общий модуль**: проекты независимы и запускаются
   каждый сам по себе. Дублирование клиентов — сознательное решение.
3. Создать `README.md`, `.env.example`, `.gitignore` (`.cache/`, `__pycache__/`).
4. Добавить строку в таблицу задач корневого `README.md`.
5. Если проект пишет результаты в корень — добавить маску `wNtM_*` в
   корневой `.gitignore`. Ловушка: маска `w1t5_*.json` заодно ловит
   одноимённые файлы конфигурации — такие называть без префикса задачи.

## Конвенции кода

- Только стандартная библиотека, Python 3.10+. Зависимостей нет и не добавлять.
- `from __future__ import annotations`, полная типизация, `dataclass` вместо
  словарей для структур.
- Идентификаторы по-английски, докстринги и комментарии по-русски.
  Комментарий объясняет «почему», а не «что».
- Функции, не классы, для логики сценария; класс — только для клиентов API.
- Ручной разбор `sys.argv` в `parse_args`, поддержка `--flag=value` и
  `--flag value`; неизвестный аргумент — ошибка с перечнем доступных.
- `main() -> int`, коды возврата `0` успех / `1` ошибка; при старте
  `stream.reconfigure(encoding="utf-8")` для stdout и stderr (Windows).
- `AppError(RuntimeError)` как единственный тип ошибки сценария; ошибка
  одного запроса не роняет прогон — пишется в результат и работа идёт дальше.
- Таблицы через `print_table(headers, rows)` (выравнивание по ширине),
  без внешних библиотек и цветов.
- Экспорт: JSON + CSV (`;`, `utf-8-sig`) в корень рядом с `tasks.json`,
  имя `<папка>_<модель>_<ГГГГ-ММ-ДД>_<ЧЧ-ММ-СС>`.

## Ловушки

- **`temperature=0.0` falsy**: передавать только через `if temperature is not None`,
  иначе нулевая температура молча выпадает из запроса.
- **`temperature=0` не гарантирует детерминизм** — при анализе разброса это
  надо оговаривать, иначе выводы неверны.
- **`precached_prompt_tokens`** — кэш префикса промпта, а не ответа.
  Ответы GigaChat не кэширует.
- **GigaChat `reasoning_effort`**: принимает `low`/`medium`/`high`, на `max`
  отвечает HTTP 422. Часть моделей Veai заявляет `max` в каталоге, но
  отклоняет его — список в `VEAI_EFFORT_REJECTED` (`w1t3/main.py`).
- **GigaChat `Embeddings`** попадает в общий список моделей — фильтровать
  по `type == "chat"`, иначе 404.
- **Сертификаты НУЦ** грузить отдельными файлами через
  `context.load_verify_locations(cadata=...)`: склеенный PEM на Windows
  не разбирается из-за CRLF.
- **Veai тарифицирует минуты, а не токены** и не имеет тарифной сетки по
  моделям. Цена запроса — оценка по прайсу вендора модели; расход минут
  считать по времени ответа и помечать как оценку.
- **GigaChat (пакеты физлица) считает вход и выход по одной ставке** —
  в `ai_models_prices.json` у него `rub_per_1m`, без `usd_in`/`usd_out`.

## Цены

`ai_models_prices.json`: поле `tier` (`small`/`medium`/`flagship`),
ставки за 1M токенов, `source` и `checked` (дата сверки), курс `usd_rub`
задаётся вручную с датой. Сверять на
`developers.sber.ru/docs/ru/gigachat/tariffs/individual-tariffs` и
`platform.claude.com/docs/en/about-claude/pricing`.

## Запуск и отладка

```powershell
python .\w1t4\main.py                  # интерактивно
python .\w1t4\main.py --temps 0,1.2 --repeat 2   # быстрый прогон
python .\w1t3\main.py --short --no-cache          # сокращённый набор
```

- Ключи в `.env` **вне репозитория** (`GIGACHAT_CREDENTIALS`, `VEAI_CREDENTIALS`),
  ищется от папки задачи вверх по дереву; `--env PATH` перебивает поиск.
- `.env` не коммитить и не печатать содержимое. Токен в логах сокращать.
- Для отладки без траты минут: `--short`, GigaChat (ответ 0.1–5 с против
  4–20 с у Veai), малый `--repeat`.
- Проверка нового сценария без реальных запросов: подменить `main.chat`
  функцией-заглушкой, вернуть правдоподобные ответы и прогнать полный путь —
  так проверялись `w1t4` и `w1t5`.
- Результаты прогонов (`w1tN_*.json/csv`) в корне — артефакты, не исходники:
  удалять после проверки, в коммит не включать.

  `git -c user.name="Andrei Shvets" -c user.email="21139767+AndreiShvets@users.noreply.github.com" commit`.
